# rabota-tgbot

# 🤖 AI Career Navigator Bot

Telegram-бот для помощи молодым людям (16–22 лет) в профессиональном самоопределении, построении карьерного трека и поиске стажировок. Использует бесплатную языковую модель через Hugging Face Inference API.

## 🚀 Возможности

- **Профориентационная диагностика** – сбор возраста, интересов, образования и навыков.
- **AI-анализ** – генерация персонализированных рекомендаций: подходящие профессии и пошаговый план развития на год.
- **Поиск стажировок и вакансий** – интеграция с hh.ru (фильтр «без опыта», ключевые слова: стажёр, junior, intern, trainee).
- **Поддержка двух языков** – русский и английский (переключается кнопкой в меню).
- **Сохранение данных** – SQLite хранит профили пользователей, историю рекомендаций и языковые настройки.
- **Удобное меню** – кнопки для всех действий.

## 📦 Требования

- Python 3.9+
- Библиотеки: `python-telegram-bot`, `huggingface-hub`, `requests`, `sqlite3` (встроена)

## ⚙️ Установка и запуск

1. **Клонируйте репозиторий или создайте файл `bot.py`** и скопируйте в него полный код бота (финальная версия с исправленным поиском вакансий).

2. **Установите зависимости**:
   ```bash
   pip install python-telegram-bot huggingface-hub requests
   ```

3. **Получите токены**:
   - Telegram Bot Token – у [@BotFather](https://t.me/BotFather).
   - Hugging Face API Key – на [huggingface.co/settings/tokens](https://huggingface.co/settings/tokens) (бесплатный, достаточно роли `read`).

4. **Вставьте токены в код** (в разделе `# ======================= КОНФИГУРАЦИЯ =======================`):
   ```python
   TELEGRAM_TOKEN = "ваш_токен"
   HF_API_KEY = "hf_ваш_ключ"
   ```

5. **Запустите бота**:
   ```bash
   python bot.py
   ```

6. **Найдите бота в Telegram** по его username и отправьте `/start`.

## 🧠 Как это работает

1. **Диагностика** – бот задаёт 4 вопроса (возраст, интересы, образование, навыки).
2. **AI-анализ** – данные отправляются в модель `Qwen/Qwen2.5-7B-Instruct` через Hugging Face Inference API. Модель возвращает профессиональные склонности и план развития.
3. **Поиск вакансий** – формируется запрос к hh.ru (текст = навыки + интересы + "стажировка junior trainee", опыт = "noExperience"). Результаты фильтруются по ключевым словам в названии (стажёр, junior, intern и др.) и отображаются пользователю.
4. **Язык** – выбранный язык сохраняется в БД, все сообщения и AI-промпты генерируются на нужном языке.

## 📋 Команды и кнопки

| Команда / кнопка | Действие |
|----------------|----------|
| `/start` | Главное меню |
| `/diagnostic` или кнопка «Пройти диагностику» | Запуск опроса |
| `/recommendations` или «Мои рекомендации» | Показать последний план развития |
| `/jobs` или «Найти вакансии» | Поиск стажировок |
| `/language` или «Сменить язык» | Переключение RU/EN |
| `/help` или «Помощь» | Справка |
| `/cancel` | Отмена активной диагностики |

## 🗄️ Структура базы данных

- `users` – профили пользователей (user_id, возраст, интересы, образование, навыки, дата создания).
- `recommendations` – сгенерированные планы (user_id, тип, содержимое, дата).
- `user_settings` – языковые предпочтения (user_id, language).

## ⚠️ Возможные проблемы и решения

| Проблема | Решение |
|----------|---------|
| Бот не отвечает на запросы | Проверьте интернет-соединение. Убедитесь, что токены вставлены правильно. |
| AI долго отвечает или возвращает ошибку | Бесплатные модели Hugging Face могут загружаться 5–15 секунд при первом запросе. Повторите попытку. |
| Не находятся вакансии | Убедитесь, что в диагностике указаны конкретные навыки (например, "Python, Django"). Попробуйте поискать вручную на hh.ru с фильтром «без опыта». |
| Ошибка `sqlite3.OperationalError: no such column` | Удалите файл `career_bot.db` и перезапустите бота – он создаст таблицы заново. |

## 🔧 Настройка под себя

- **Сменить AI-модель** – замените `MODEL_NAME` на любую другую модель, доступную через бесплатный Inference API (например, `"mistralai/Mistral-7B-Instruct-v0.3"`).
- **Изменить возрастные ограничения** – отредактируйте проверки `age < 14 or age > 30` в функции `diagnostic_age`.
- **Расширить поиск вакансий** – добавьте дополнительные источники (например, Careerist.ru, LinkedIn) в функцию `find_vacancies`.
